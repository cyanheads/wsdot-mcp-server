# 0.4.2 — 2026-10-25

## Changed

- **Tool text rendering** encodes upstream names, descriptions, notes, timestamps, filters, and notices through the framework's Markdown helpers so clients read the original strings after CommonMark parsing.
- **Camera images** render as Markdown images with their original HTTP(S) destinations; other URL forms render as literal text.
- **Server instructions** identify upstream alert descriptions, bulletins, sailing notes, and names as data.
- **Framework 0.13.16** supplies escaped error and enrichment text, bounded configuration with variable-specific startup diagnostics, cancellation settlement, and HTTP shutdown fixes; 0.13.15 supplies bounded Zod error details and summary logging.
- **Hosted setup documentation** gives separate Claude Code, Cline, Cursor, and Claude Desktop connection instructions; `.env.example` documents request-state sealing, replay retention, and interaction logging settings.
- **Build tooling** refreshes framework skills, uses Bun 1.4.4 container stages, excludes source and development directories from MCPB bundles, and attributes shared audit advisories against the root-installed dependency version.

## Fixed

- **Parser complexity tests** measure thread CPU time so worker scheduling delays do not count as parser work.
