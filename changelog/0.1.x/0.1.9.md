# 0.1.9 — 2026-06-08

## Fixed

- **WCF `/Date(ms±offset)/` timestamps** now decode to ISO 8601 across all traffic tools (`mountain_passes`, `toll_rates`, `travel_times`, `search_alerts`); `.NET DateTime.MinValue` emits as `null`. New shared `decodeWcfDate`/`wcfDateField` util used by both services — ferry-side already decoded, traffic-side now consistent. ([#11](https://github.com/cyanheads/wsdot-mcp-server/issues/11))
- **`wsdot_get_mountain_passes` elevation and restriction fields** were silently dropped: the mapper read non-existent upstream fields (`Elevation`, `RestrictionOne.TravelRestrictionComment`, `RestrictionOne.RestrictionType`); corrected to `ElevationInFeet`, `RestrictionText`, and `TravelDirection`. Restriction shape normalized to `{ text, travelDirection }`. ([#12](https://github.com/cyanheads/wsdot-mcp-server/issues/12))
- **Ferry 4xx responses** are no longer retried (marked non-retryable; previously burned 4 attempts on client errors). `toFerryDate` now rejects non-`YYYY-MM-DD` input locally (e.g. `06/08/2026`). Terminal-pair 4xx responses map to a clear `invalid_terminal_pair` error. ([#13](https://github.com/cyanheads/wsdot-mcp-server/issues/13))
- **`wsdot_get_border_waits` crossing descriptions** updated: `crossingName` values are route codes (`I5`, `SR543`, `SR539`, `SR9`) — the previous "Peace Arch, Pacific Highway, Lynden, Oroville" prose was inaccurate. `location.description` now surfaced as the human-readable name. The `-1` no-data sentinel is documented and omitted from output. `wsdot_get_ferry_alerts` and `wsdot_get_ferry_routes` cross-reference note updated: San Juan interisland and Sidney B.C. route IDs don't resolve via `wsdot_get_ferry_routes`. ([#14](https://github.com/cyanheads/wsdot-mcp-server/issues/14))

## Changed

- **Direction code legend** added to every direction `.describe()`: cameras (`B`=both, `N/S/E/W`, `O`=other), alerts (`A`=alternating, `B`=both, `N/S/E/W`), travel times (`N/S/E/W`), border waits (`N/S/E/W`), and toll rates `travelDirection` (`N/S/E/W`). ([#15](https://github.com/cyanheads/wsdot-mcp-server/issues/15))
