# 0.1.8 — 2026-06-08

## Fixed

- **`wsdot_get_toll_rates`** — `RawTollRate` field names corrected to match the WSDOT API (`CurrentToll`, `CurrentMessage`, `TravelDirection`, `StartLatitude`/`Longitude`, `EndLatitude`/`Longitude`); `tollRateInDollars` now populated as `CurrentToll / 100` and all location fields passed through. Previously every row returned 0 toll amount ([#8](https://github.com/cyanheads/wsdot-mcp-server/issues/8)).
- **`wsdot_search_alerts`** — filtered calls now query `GetAlertsAsJson` (active feed, ~166 records) and filter client-side instead of routing to `SearchAlertsAsJson` (full historical archive, up to 28 s / 2.5 MB). Region input normalizes full names to internal codes (`Northwest → NW`, etc.) ([#9](https://github.com/cyanheads/wsdot-mcp-server/issues/9)).
- **`wsdot_search_cameras`** — location fields (`roadName`, `milePost`, `latitude`, `longitude`, `direction`) now populated by unpacking the `CameraLocation` nested object. Filtered calls now query `GetCamerasAsJson` (full 1,682-camera feed) and filter client-side; `stateRoute` and `region` filters previously returned 0 results ([#10](https://github.com/cyanheads/wsdot-mcp-server/issues/10)).

## Changed

- **`devcheck.config.json`** — `@cyanheads/mcp-ts-core` added to `outdated.allowlist` (held at 0.9.21; framework adoption is separately managed).

## Dependencies
