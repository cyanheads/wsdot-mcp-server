# 0.1.13 — 2026-07-11

## Fixed

- **Ferry default trip date** — `FerryApiService.todayFerryDate()` now returns the Washington service date (`America/Los_Angeles`) instead of the UTC date, so ferry tools that default `tripDate` to today (`wsdot_get_ferry_routes`, `wsdot_get_ferry_schedule`) resolve the correct service day; the UTC date rolls over to tomorrow during the Pacific evening and queried the next day's sailings ([#16](https://github.com/cyanheads/wsdot-mcp-server/issues/16)).
- **`wsdot_get_vessel_locations` coordinate parity** — `content[]` now renders latitude/longitude at full upstream AIS precision instead of rounding to five decimals, so it matches `structuredContent` and the two channels carry identical vessel positions ([#21](https://github.com/cyanheads/wsdot-mcp-server/issues/21)).
- **`wsdot_get_ferry_routes` output description** — README and `docs/design.md` corrected to the tool's actual output surface (route ID, abbreviation, and description); the prior text claimed terminal ID pairs and crossing times the tool does not return. Numeric terminal IDs come from `wsdot_get_ferry_terminals` ([#19](https://github.com/cyanheads/wsdot-mcp-server/issues/19)).
