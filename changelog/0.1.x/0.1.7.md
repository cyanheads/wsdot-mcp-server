# 0.1.7 — 2026-06-04

## Changed

- **`wsdot_get_ferry_routes` / `wsdot_get_ferry_schedule`** — invalid `tripDate` values now throw via `ctx.fail('invalid_date', …)` so the declared contract reason populates `data.reason` on the wire ([#6](https://github.com/cyanheads/wsdot-mcp-server/issues/6)).
- **`wsdot_get_ferry_schedule`** — API errors matching `WSF Ferry API error` now throw via `ctx.fail('invalid_terminal_pair', …)` with a recovery hint pointing to `wsdot_get_ferry_terminals` and `wsdot_get_ferry_routes` ([#6](https://github.com/cyanheads/wsdot-mcp-server/issues/6)).

## Fixed

- **`FerryApiService.getSchedule`** — `remainingOnly=true` with a future `tripDate` now correctly returns the future date's full schedule instead of today's remaining sailings ([#5](https://github.com/cyanheads/wsdot-mcp-server/issues/5)). The `remainingOnly` flag is now only applied when `tripDate` equals today.
